# Oil Rush: Strait of Hormuz

Real-time multiplayer top-down naval game.

Players sign in with Google, navigate ships through the Strait of Hormuz, load/deliver oil cargo, avoid mines and coast guard patrol, and compete online.

## Stack
- React + Vite + HTML5 Canvas
- Express 5 + Socket.io
- Firebase Auth + Firestore
- TypeScript · pnpm workspaces

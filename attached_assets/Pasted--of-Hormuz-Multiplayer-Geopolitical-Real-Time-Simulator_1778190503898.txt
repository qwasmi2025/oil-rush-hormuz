 of Hormuz
النوع: Multiplayer Geopolitical Real-Time Simulator
اللاعبون: 3–7
مدة الجولة: 10–15 دقيقة
المنصة: Web Browser
التحكم: Click-to-Move
الفكرة: 7 دول تتنافس على مضيق هرمز. كل دولة أهداف مختلفة، كل دولة سلاح مختلف — اقتصاد، جيش، دبلوماسية.

2. CORE LOOP

    ↓

    ↓

    ├── ⚓ Naval Layer    → سفن تتحرك وتشحن نفط
    ├── 💰 Economy Layer → سعر النفط يتغير كل 30 ثانية
    ├── 🤝 Diplomacy     → اتفاقيات + خيانات
    └── 📰 Events        → AI يولّد حدث كل 90 ثانية
    ↓
RESULTS — podium + share button + غرفة جديدة

function updateShip(ship, dt) {
  if (!ship.target) return
  const dx = ship.target.x - ship.x
  const dy = ship.target.y - ship.y
  const dist = Math.hypot(dx, dy)
  if (dist < 6) { ship.target = null; return }
  const spd = NATION_STATS[ship.nation].speed
  ship.angle = Math.atan2(dy, dx)
  ship.x += Math.cos(ship.angle) * spd * dt
  ship.y += Math.sin(ship.angle) * spd * dt
}

7. DIPLOMACY
الأدوات:

اتفاقية تجارية — تتشاركان 10% من أرباح بعض
تحالف دفاعي — هجوم على واحدة = الثانية تدخل
اتفاقية سرية — بس الطرفان يشوفانها (قابلة للخيانة)
عقوبات — تجمد 30% أرباح المستهدف (تحتاج 2 دول معك)
إعلان حرب — يفتح الاشتباك الكامل، توتر +40
طلب وساطة — تستدعي عُمان للتفاوض

الخيانة:
وقّع اتفاقية مع X، ثم اتفاقية سرية مع Y لتهاجموا X. النتيجة: "خيانة دبلوماسية!" على شاشة الجميع + الخائن يخسر -50 نقطة سمعة.

9. GAME MODES
Rush Mode (الافتراضي): 7 دول، 10 دقائق، كل واحد يحقق هدفه.
Storm Survival: عاصفة تضيق كل دقيقة، آخر دولة محافظة على أسطولها تفوز.
Cartel Mode: 3 ناقلات vs 4 دول. الناقلات تعبر، الدول تمنعهم. خيانة داخل الفريق مسموحة.
Daily Challenge: نفس seed يومياً للجميع، 90 ثانية، نتيجة قابلة للمشاركة (Wordle effect).
